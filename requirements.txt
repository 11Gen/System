# 中国名菜识别与营养摄入估算系统 —— 依赖清单
#
# 安装：
#     pip install -r requirements.txt
#
# 说明：
#   1. 这里用 >= 指定最低版本，不精确锁定到某个小版本。
#      原因是 PyTorch 的 wheel 是按 Python 版本分别编译的，
#      如果把版本卡死，换一个 Python 版本就会找不到对应的 wheel。
#      项目在 Python 3.13 与 3.14 上都验证过能装。
#
#   2. torch 与 torchvision 必须版本配套，不能各装各的最新版。
#      下面按官方对应关系给出下限（torch 2.11 配 torchvision 0.26）。
#      另外 torchvision 的版本不能单独升级，否则会报
#      "operator torchvision::nms does not exist" 这类错误。
#
#   3. 默认装 CPU 版 torch 即可跑完全流程。
#      想用 NVIDIA 显卡加速的话，先装 CPU 版确认流程通了，
#      再按 https://pytorch.org/get-started/locally/ 换装 CUDA 版。
#      注意 CUDA 版本要匹配显卡驱动支持的版本。

torch>=2.11.0
torchvision>=0.26.0
